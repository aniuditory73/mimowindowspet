# MIMO

Компактная настольная утилита на Rust и Slint. Первый этап включает островок, панель задач, меню в области уведомлений Windows и локальную проверку отклика приложения.

## Сборка и запуск

Для сборки нужны Windows x64, Rust stable 1.92 или новее с целью `x86_64-pc-windows-msvc`, MSVC Build Tools и Windows SDK. В установщике Visual Studio Build Tools выберите «Разработка классических приложений на C++». Cargo загружает зависимости при первой сборке. Для запуска MIMO достаточно обычной учётной записи Windows, доступ к сети во время работы приложения не требуется.

```powershell
rustup component add rustfmt clippy
cargo run --locked
```

Нажмите на островок MIMO, чтобы открыть панель. Кнопка «Проверка отклика» и команда `проверка отклика` запускают восьмисекундную задачу. Во время её выполнения можно свернуть панель, открыть настройки, отправить ещё одну задачу в очередь или нажать «Отменить». Через меню значка MIMO в области уведомлений можно открыть панель, скрыть островок и завершить работу. Windows может поместить значок под стрелку скрытых значков.

## Настройки и разрешения

MIMO хранит положение островка в `%LOCALAPPDATA%\MIMO\settings-v1.txt`. Откройте «Настройки», чтобы выбрать угол рабочей области ближайшего монитора. В новой установке используется верхний правый угол. Пример находится в [settings-v1.example.txt](examples/settings-v1.example.txt). При переносе настроек между установками скопируйте файл в каталог MIMO с закрытым приложением. Неизвестная версия файла вызывает ошибку чтения и сохраняется на диске для миграции.

В этом этапе приложение обращается к собственным настройкам. Поддерживается только локальная команда проверки отклика. Пользовательские папки не входят в область доступа. На втором этапе доступ к папке будет предоставляться явным выбором и проверяться для каждой операции. Окно использует обычный порядок наложения Windows и доступно через область уведомлений, если его перекрыли другие окна.

## Codex CLI

Интеграция запланирована на третий этап. Локальные команды MIMO работают без Codex. Для делегирования потребуется поддерживаемая версия CLI, авторизация официальными средствами Codex и явно выбранная папка проекта. Доступность удалённых задач будет зависеть от сети, учётной записи и лимитов сервиса.

## Проверки и материалы проекта

```powershell
cargo fmt --all -- --check
cargo check --locked --all-targets
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --all-targets
cargo build --locked
```
