# MIMO

Компактная настольная утилита на Rust и Slint. MIMO объединяет локальные заметки, просмотр и сортировку выбранных папок, историю задач и делегирование анализа проекта в Codex CLI.

## Сборка и запуск

Для сборки нужны Windows x64, Rust stable 1.92 или новее с целью `x86_64-pc-windows-msvc`, MSVC Build Tools и Windows SDK. В установщике Visual Studio Build Tools выберите «Разработка классических приложений на C++». Cargo загружает зависимости при первой сборке. Для запуска MIMO достаточно обычной учётной записи Windows, доступ к сети во время работы приложения не требуется.

```powershell
rustup component add rustfmt clippy
cargo run --locked
```

Нажмите на островок MIMO, чтобы открыть панель. Кнопка «Проверка отклика» и команда `проверка отклика` запускают восьмисекундную задачу. Во время её выполнения можно свернуть панель, открыть настройки, отправить ещё одну задачу в очередь или нажать «Отменить». Через меню значка MIMO в области уведомлений можно открыть панель, скрыть островок и завершить работу. Windows может поместить значок под стрелку скрытых значков.

Для отдельной сборки используйте `cargo build --locked --release` и запустите `target\release\mimo.exe`. `Ctrl+Alt+M` открывает панель. Если сочетание занято, об этом будет указано в настройках.

## Настройки и разрешения

MIMO хранит угол и режим закрепления в `%LOCALAPPDATA%\MIMO\settings-v1.txt`. Откройте «Настройки», чтобы выбрать угол рабочей области ближайшего монитора. В новой установке используется верхний правый угол. Пример находится в [settings-v1.example.txt](examples/settings-v1.example.txt). При переносе настроек между установками скопируйте файл в каталог MIMO с закрытым приложением. Неизвестная версия файла вызывает ошибку чтения и сохраняется на диске для миграции.

Островок и панель закреплены поверх обычных окон по умолчанию. Кнопка «Закреплено» в панели отключает закрепление, а кнопка «Закрепить» включает его снова. Когда активное окно занимает весь монитор MIMO, закрепление временно приостанавливается. Через область уведомлений Windows панель можно открыть в любом режиме.

Команда `запомни: Купить хлеб` сохраняет короткую заметку. Кнопка «Заметки» показывает последние записи. Для поиска введите слово в поле поиска или команду `найди заметки: хлеб`. Нажмите на запись, чтобы открыть её полностью. «Изменить» и «Заменить текст» сохраняют редакцию открытой заметки. Текст хранится в `%LOCALAPPDATA%\MIMO\notes-v1` в UTF-8. Напоминания по тексту заметок не создаются.

В разделе «Файлы» введите полный путь к папке на локальном диске и нажмите «Разрешить просмотр». Предпросмотр показывает до 30 переносов изображений и документов из верхнего уровня в одноимённые категории. Перенос требует отдельного подтверждения. Коллизии, блокировки и изменения после просмотра оставляют соответствующий файл на месте. «Вернуть файлы» возвращает результаты последнего переноса в текущем сеансе, если исходное имя свободно и файл сохранил проверяемые атрибуты. Пустые папки категорий сохраняются.

Для переименования выберите «Переименовать», укажите исходное и новое имена в той же папке и нажмите «Проверить». Изменение также проходит через предпросмотр и подтверждение.

«История» показывает до 40 результатов. Журнал хранит только вид и конечный статус операции, без запросов, заметок, путей и ответов Codex.

## Codex CLI

Войдите через официальный `codex login` и нажмите «Проверить CLI» в панели MIMO. Приложение ищет `codex.exe` в `PATH` и в каталоге установленного Codex для Windows. Для анализа укажите папку проекта и запрос, затем подтвердите отправку. Запуск использует профиль чтения и требует доступной песочницы MXC. Локальные функции MIMO работают без Codex. Доступность удалённых задач зависит от сети, учётной записи и лимитов сервиса. [Справка Codex CLI](https://learn.chatgpt.com/docs/developer-commands?surface=cli) · [Windows MXC](https://learn.chatgpt.com/docs/windows/windows-sandbox)

Перед подтверждением MIMO показывает папку и запрос. Codex может передать OpenAI данные, доступные ему для анализа. MIMO получает итоговое сообщение Codex, отображает его как ответ модели и хранит его только в памяти. Вызовы инструментов ограничивает песочница Codex и системная политика Windows. На Windows без MXC доступен локальный режим MIMO.
