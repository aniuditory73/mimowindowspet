# Зависимости и лицензирование

| Прямая зависимость | Версия | Назначение | Лицензирование upstream |
| --- | --- | --- | --- |
| `slint` | 1.18.1 | Нативный UI, программный рендерер, системный трей | GPL-3.0-only или отдельные лицензии Slint |
| `slint-build` | 1.18.1 | Компиляция Slint на этапе сборки | GPL-3.0-only или отдельные лицензии Slint |
| `raw-window-handle` | 0.6.2 | Доступ к дескриптору окна из Slint | MIT или Apache-2.0 или Zlib |
| `windows-sys` | 0.61.2 | Вызовы Windows API | MIT или Apache-2.0 |
| `serde_json` | 1.0.154 | Декодирование событий Codex CLI | MIT или Apache-2.0 |

`Cargo.lock` фиксирует версии. Для списка транзитивных зависимостей, активных на целевой платформе, используйте `cargo tree --locked --target x86_64-pc-windows-msvc`. Перед выпуском бинарника нужно сформировать перечень лицензий и уведомлений для собранной конфигурации.

Предложение владельцу проекта — MIT для исходников MIMO и распространение бинарника, собранного с GPL-вариантом Slint, на условиях GPLv3 для всей сборки. Окончательный выбор лицензии MIMO ожидает решения владельца. [Варианты лицензирования Slint](https://slint.dev/get-started)
