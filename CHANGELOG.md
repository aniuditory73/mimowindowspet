# Журнал изменений

## В разработке

- Оболочка MIMO на Windows с островком, компактной панелью и меню в области уведомлений.
- Выбор и локальное сохранение угла окна.
- Закрепление поверх обычных окон по умолчанию с переключателем в панели и временной паузой для полноэкранного окна на том же мониторе.
- Фоновая очередь для проверки отклика, отмена, прогресс и результат последней задачи в текущем сеансе.
- Локальные заметки с созданием, списком, поиском, просмотром и редактированием записи.
- Просмотр явно выбранной папки, предпросмотр сортировки и переименования, перенос без перезаписи с возвратом последней операции в сеансе.
- Обнаружение Codex CLI и подтверждаемый анализ проекта с профилем чтения, тайм-аутом и отменой.
- История завершённых задач и сочетание Ctrl+Alt+M.
